# ADR-0003 React + TypeScript + Vite

**Date:** 2026-10-23 · **Status:** Accepted

## Context
Most experience with React/JS; wants to learn TypeScript; long-term maintainability matters.

## Decision
React SPA built with Vite, TypeScript throughout (frontend and API), mobile-first.

## Consequences
Shared types between API and UI. SEO for public fixture pages may later need pre-rendering or SSR.
