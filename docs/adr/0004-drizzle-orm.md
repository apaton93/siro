# ADR-0004 Drizzle ORM

**Date:** 2026-10-23 · **Status:** Accepted

## Context
No prior ORM experience; heavy use of PostGIS.

## Decision
Drizzle ORM, with Drizzle Kit for migrations.

## Consequences
TypeScript-first and SQL-like; PostGIS via custom types or raw SQL. Smaller ecosystem than Prisma.
