# ADR-0008 No flight/hotel APIs in MVP

**Date:** 2026-10-23 · **Status:** Accepted

## Context
Travel APIs add cost and complexity; the core value is the fan community.

## Decision
Outbound links only for flight and hotel search. Reference data (fixtures, stadiums, airports, guides, venues) is entered manually by an admin.

## Consequences
Fast MVP; manual effort per fixture. Revisit APIs and affiliate links after the first release.
